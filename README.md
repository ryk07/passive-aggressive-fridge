# Notes From a Passive-Aggressive Fridge

One original funny passive-aggressive note, written by a small Python program
(`main.py`) that writes it to `/output/entry.txt`.

The note: a smart fridge counts how many times its owner opened it and took
nothing, then delivers the verdict — it is not a museum, and the yogurt is
not an exhibit.

Built for the [Notes From a Passive-Aggressive Fridge](https://make.fun/c/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7)
bounty on [make.fun](https://make.fun).
